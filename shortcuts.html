.du

Find duplicate items

.fb

Generate Fibonacci numbers

.pr

Check whether a number is prime

.fa

Calculate a factorial

.pa

Check a palindrome

.an

Compare two words

.fr

Count item frequency

.rv

Reverse a string

.sl

Find the second-largest number

.sd

Sort a dictionary by value

.mi

Find a missing number

.http

Validate HTTP response status

.log

Find ERROR entries in a log file

.alarm

Find the most frequent alarm

.ip

Validate IPv4 / IPv6 addresses

.sub

Calculate subnet details

.route

Find the longest-prefix route

.logip

Count IP addresses in logs

.json

Validate a network event payload

.retry

Simulate API retry handling

.qos

Check latency against a threshold

.port

Identify common network ports

.tcpudp

Compare TCP and UDP behavior

.dns

Practise DNS lookup logic

.fl

Count and filter lines

How to use: Keep this guide open in another browser tab. Return to the IDE, type the shortcut (for example, .ip) in the editor, then press Enter or Tab to expand the Python example. The shortcut definitions remain in the IDE; this page is a separate reference.
